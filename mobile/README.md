# House of Sauces mobile app

This Flutter application provides the owner and branch-admin workflows for House of Sauces.

For backend setup, Android development, USB installation, release signing, and deployment guidance, see the [project README](../README.md).

## Run locally

Install Flutter 3.47+ and the Android SDK, start the backend as described in the project README, then run:

```powershell
flutter pub get
flutter run
```

For emulator or USB-connected device setup, use the API URL and scripts documented in the project README.
